   # Política de Segurança

   ## Versões suportadas
   Apenas a versão mais recente do site (branch main) recebe correções.

   ## Como reportar uma vulnerabilidade
   Abra uma Issue neste repositório com o título "[Segurança]" e descreva o problema.
   Não inclua senhas, tokens ou dados pessoais no relato.

   ## Práticas adotadas
   - Autenticação em dois fatores na conta do GitHub
   - Secret scanning e Dependabot alerts ativados
   - Branch main protegida (alterações somente por Pull Request)
   - Nenhuma credencial armazenada no repositório
