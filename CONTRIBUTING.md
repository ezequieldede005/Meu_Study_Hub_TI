   # Como colaborar

   1. Faça um fork do repositório (ou peça acesso como colaborador).
   2. Crie uma branch: git checkout -b minha-melhoria
   3. Faça as alterações e commits com mensagens claras (ex.: "feat: adiciona seção X").
   4. Envie a branch e abra um Pull Request para a main.
   5. Aguarde a revisão. Alterações entram na main apenas por Pull Request.

   Use Issues para sugerir melhorias ou relatar problemas.
